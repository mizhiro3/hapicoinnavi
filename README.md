# はぴコイン使えるお店ナビ

## 福井のデジタル地域通貨を、もっと見つけやすく

「はぴコイン使えるお店ナビ」は、ふくいはぴコインをはじめとする地域のサイフ・ポイントや紙商品券が使えるお店を、現在地や店名、住所、カテゴリから探しやすくするWebサイトです。

地域通貨を使いたいと思っても、「近くではどのお店が対応しているのか」「飲食店やスーパーだけに絞り込めるか」「複数のコインが使えるお店はどこか」といった情報を、外出先のスマートフォンですぐに確認するのは簡単ではありません。本サイトは、店舗情報を検索しやすい形に整理し、使えるお店との出会いを支援します。

## 現在地から、近いお店をすぐに検索

利用者が許可した場合に限り、端末の現在地から近い順で対応店舗を表示します。現在地は端末内の距離計算だけに使い、保存・外部送信しません。位置情報を使わない場合も、店名・住所のフリーワード検索やカテゴリ絞り込みを利用できます。

## 使いたいコインから迷わず探せる

トップページで利用したいサイフ・ポイントまたは紙商品券を選ぶと、その支払手段に対応する店舗だけを一覧表示します。食品、ショッピング、飲食、サービスなどの分類から、目的に合うお店へ素早くたどり着けます。

店舗カードでは、そのお店で使える複数の支払手段もまとめて確認できます。

## スマートフォンの通信量と操作性にも配慮

トップページでは大容量の店舗データを読み込まず、コインを選択したときに初めて取得します。店舗一覧は距離順や検索順を維持したまま段階的に表示し、変更のないデータや画像は端末のキャッシュを活用します。外出先でも、通信量と画面描画の負荷を抑えて利用できる設計です。

## 地域で使う人と、地域のお店をつなぐ

地域通貨は、使える場所が分かってこそ日常の選択肢になります。「はぴコイン使えるお店ナビ」は、利用者が身近な参加店を見つけ、地域の店舗を選ぶきっかけを増やすことを目指します。

本サイトは公式な加盟証明や営業保証を行うものではありません。営業時間や対応状況などは参考情報として扱い、最新情報は各店舗および公式案内もあわせてご確認ください。
